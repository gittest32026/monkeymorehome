[Monkeymore工作室](https://www.monkeymore.app)在过去几年开发的所有产品，都是经典的游戏或者工具，但是细节上有自己的特点。

## 小游戏

### 益智游戏

- [七巧板](https://tangram.monkeymore.app) - 上千个免费七巧板谜题，从经典动物造型到海量题库，在线拼图，也可以导出PDF给孩子玩。

- [华容道](https://klotski.monkeymore.app) - 480个经典关卡，从横刀立马到梦魇难度，按最少步数排序，支持提示与自动演示。

- [24点游戏](https://game24.monkeymore.app) - 数百道精心设计的关卡，用加、减、乘、除把四个数字算出24。

- [火柴等式](https://mathstick.monkeymore.app) - 挪动一根或几根火柴让错误的等式变成正确的等式，400道关卡由易到难。

- [数独](https://sudoku.monkeymore.app) - 经典9×9数独含6个难度级别，还有杀手、奇偶、锯齿、连续等变体，支持生成题目、求解、拍照识别。

- [魔尺](https://rubiksnake.monkeymore.app) - 在线3D互动魔尺，体验经典的魔尺 puzzle。


### 休闲游戏

- [跳一跳](https://jump.monkeymore.app) - 免费的3D跳跃小游戏，浏览器里即点即玩。

- [推箱子](https://sokoban.monkeymore.app) - 数百个关卡，通关战役模式，还能浏览社区关卡合集。

- [2048](https://2048.monkeymore.app) - 经典2048数字合成游戏。

- [数字游戏合集](https://numberhunter.monkeymore.app) - Number Hunter、Number Pop、Number Spot三款训练专注力与反应力的数字游戏。

- [涂色](https://colorfy.monkeymore.app) - 数百张免费在线涂色页，精美的SVG图案，适合孩子和大人的数字涂色游戏。

- [拼图](https://jigsaw.monkeymore.app) - 在线拼图乐园，挑战你的观察力。

- [俄罗斯方块](http://tetris.monkeymore.app) - 40行、闪电战、禅境、自定义、人机对战和多人模式。

- [找茬游戏](http://spotdiff.monkeymore.app/) - 每日关卡、主题合集，考验观察力的找不同游戏。

- [麻将接龙](https://mahsolitaire.monkeymore.app/) - 六款免费在线消除游戏：麻将接龙、麻将连连看、麻将消除、3D方块消除等，无需注册没有广告。

- [纸牌接龙](https://solitaire.monkeymore.app/) - 克朗代克、空当接龙、蜘蛛纸牌、金字塔等多种纸牌游戏，无需下载注册。


### 棋牌游戏

- [国际象棋](https://chess.monkeymore.app) - 互动棋题训练：Chess Tactics Art 2434题、Polgar将杀4457题，还支持PGN导入练习。

- [中国象棋](https://xiangqi.monkeymore.app) - 在线对弈：创建房间邀请好友，或挑战AI引擎。

- [围棋](https://goboard.monkeymore.app) - 精选200道经典死活题，覆盖入门到进阶，每日在线练习。

- [五子棋](https://gomoku.monkeymore.app) - 在线五子棋对弈。

- [麻将](https://mahjong.monkeymore.app) - 日麻练习站：好友建房对战、机器人陪练，还有何切三百问题库。

- [斗地主](https://doudizhu.monkeymore.app) - 棋牌大厅含七种扑克玩法：斗地主、掼蛋、双扣、跑得快等，真人实时对战，人数不足时电脑自动补位。

- [台球](https://billiards.monkeymore.app/) - 真实物理引擎的浏览器台球：单人经典15球、创意关卡，以及斯诺克、中式黑八、美式八球、九球的实时对战。

### io游戏

- [贪吃蛇](https://snake.monkeymore.app) - 多人在线贪吃蛇：经典生存模式、40人在线对战、自定义皮肤。

## 工具

- [图片工具](https://imageconv.monkeymore.app/) - 图片格式转换（50+格式）、压缩（WebP/AVIF）、裁剪旋转翻转，无需登录，100%隐私。

- [视频工具](http://videotool.monkeymore.app/) - 视频转换、压缩、裁剪、合并、提取音频、加字幕等，全部在浏览器本地处理。

- [PDF工具](https://pdf.monkeymore.app/) - PDF合并、拆分、压缩、转换、旋转、解锁、加水印，浏览器本地处理，无需注册。

- [电子书工具](https://texttool.monkeymore.app/) - MOBI/EPUB电子书工具，浏览器本地处理，文件不上传任何服务器。

- [局域网文件共享](https://airdrop.monkeymore.app/) - 类似AirDrop的局域网文件传输：端到端直连不上传服务器，支持实时聊天和大文件分片断点续传，无需注册。

- [二维码生成器](https://qrcode.monkeymore.app/) - 免费二维码生成器，支持方形、圆形和动态样式，可批量生成。

- [头像生成](http://avatar.monkeymore.app/) - 11种风格一键生成专属头像（DiceBear、Multiavatar、Robohash等），高清PNG透明背景，无需注册。
